# Приглашение на свадьбу · 20.09.2026

Одностраничный сайт для гостей. Всё в одном файле `index.html` — шрифты подключаются
из интернета, картинки вшиты внутрь, сборка не нужна.

## Как выложить (GitHub Pages)

Репозиторий → **Settings → Pages** → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)` → Save.
Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

Дальше любое изменение: правим `index.html` → коммит → пуш, сайт обновится сам.

## Форма «Подтвердите присутствие»

Ответы гостей уходят боту в Telegram **через прокси** — файл `rsvp-worker.js`.

Почему не напрямую: чтобы отправить сообщение боту, нужен его токен, а страницу видят
все гости. Токен со страницы легко достать и получить полный доступ к боту — включая
переписку в свадебных чатах. Поэтому токен лежит в секретах прокси и наружу не выходит.

### Настройка прокси (бесплатно, ~5 минут, карта не нужна)

1. `dash.cloudflare.com` → **Workers & Pages** → Create → Worker → Deploy
2. **Edit code** → вставить содержимое `rsvp-worker.js` → Deploy
3. **Settings → Variables and Secrets** → добавить:
   | Имя | Значение |
   |---|---|
   | `BOT_TOKEN` | токен бота от @BotFather |
   | `CHAT_ID` | `448972008` — личный чат с ботом |
   | `ALLOW_ORIGIN` | `https://<логин>.github.io` — адрес сайта |
4. Скопировать адрес воркера (вида `https://xxx.workers.dev`)
5. В `index.html` найти `ВСТАВЬТЕ_СЮДА_АДРЕС_ПРОКСИ` и заменить на этот адрес

После этого каждая заполненная анкета придёт в Telegram: имя, телефон, придёт или нет,
сколько человек и с кем, напитки, аллергия, пожелание молодожёнам.

Пока прокси не настроен, гость увидит honest-сообщение «не получилось отправить,
напишите нам в мессенджер» — ответ не потеряется молча.

## Что внутри

- Обложка с датой, программа дня, место проведения, дресс-код с палитрой и фото,
  детали (о малышах, о подарках), форма подтверждения.
- Мобильная вёрстка: проверено на 375px, тапабельные зоны от 44px, первый экран
  помещается целиком.
- Уважает системную настройку «уменьшить движение».
